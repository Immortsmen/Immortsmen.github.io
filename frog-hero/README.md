# 奶蛙勇者 · 七章营救之旅

原生 JavaScript + Canvas 2D 前端小游戏。无需安装依赖，无外链素材或运行时网络请求。

## 启动

需要 Node.js 18 或更新版本。在本目录打开终端：

```sh
npm start
```

浏览器访问 http://127.0.0.1:5173 。如端口被占用，可通过 `PORT` 环境变量指定其他端口。不要直接双击 HTML，ES 模块需要 HTTP 服务。

```sh
npm test
npm run build
```

`build` 将可部署的静态文件输出到 `dist/`。也可以在项目目录执行 `python -m http.server 5173 --bind 127.0.0.1`。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 在战斗区域内移动 |
| 按住 F | 奶球连续射击，自动瞄准最近敌人 |
| 按住 Space | 防御减伤，移动速度降低 |
| Shift | 肚皮冲撞，穿过盾牌；2 次储备，每 3.5 秒恢复 1 次 |
| E | 满能量释放范围大笑 |
| C | 消耗黄桃罐头，回满生命 |
| V | 召唤奶蛋，8 秒自动强化射击，冷却 35 秒 |
| 连点 R，再按 Q | 最终章积攒 20 次笑意，释放一次超级大笑 |
| Esc | 暂停 / 继续 |

鼠标可按住底部奶球、防御按钮。触屏设备提供方向键和技能键，推荐横屏。暂停页可以调整声音。浏览器可能在首次点击前阻止音频，点一次按钮即可启用。

## 玩法与存档

- 七个区域：奶笑村、咕嘎小径、刀盾山道、风暴断桥、禁声堡垒、肃静大殿、无声王座。
- 前六章分波战斗，后续区域加入首领。最后一章为魔王战。
- 清波后恢复部分生命，并三选一强化；第一波必有自动奶球可选。
- 盾牌减少正面奶球伤害，冲撞与大笑可以突破。红色落点提示敌人的攻击位置。
- 击败敌人获得本局补给币，每章结束后可购买回血或罐头。
- 每波入口保存检查点到浏览器 `localStorage`；刷新或继续游戏从该波入口恢复，不保存当前波内的位置和击杀。失败免费重试。不会跨浏览器或设备同步。
- 页面失焦或切到后台会自动暂停，避免离开页面时被击败。

## 文件

- `engine.mjs`：不依赖浏览器的战斗与章节状态机。
- `renderer.js`：自绘场景、角色、弹幕及特效。
- `app.js` / `style.css`：菜单、键盘、触屏、存档和响应式界面。
- `audio.js`：合成音乐和音效。
- `tests/game.test.mjs`：章节推进、战斗碰撞、防御、存档与技能检查。
- `server.mjs`：仅监听本机的静态服务器。
